An app or a program

The rest of this site is about programs: a script, a page or an AI agent that uses the robot through Dev, with a key. Focus and Pet are apps: servers the robot connects to itself, as it connects to Dev. The robot runs one app at a time; its app switcher (the QR screen: Next, Connect) moves between them.

Each case study maps what the app does to Dev's actions, so a program can do the same where Dev's API reaches.
